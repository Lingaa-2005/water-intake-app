# 💧 HydroTrack Pro — Smart Water Intake Tracker

## 🚀 Overview

HydroTrack Pro is a modern, gamified water intake tracking web application designed to help users build healthy hydration habits. It transforms a simple daily task into an engaging experience using streaks, achievements, and visual progress tracking.

---

## 🎯 Features

* 💧 One-tap water logging (+250ml / +500ml)
* 📊 Animated progress visualization (water fill effect)
* 🎯 Custom daily goal setting
* 🔥 Streak tracking system
* 🏆 Achievement badges (Beginner → Gold)
* 🔔 Hourly hydration reminders
* 🌙 Dark mode toggle
* 🔊 Sound feedback on interaction
* 🕛 Automatic daily reset

---

## 🧠 Concept & Inspiration

Modern health apps use **gamification techniques** like streaks, badges, and progress tracking to increase engagement and habit formation. Research shows that gamified apps significantly improve user consistency and motivation.

---

## 🛠️ Tech Stack

* HTML5
* CSS3 (Glassmorphism + gradients)
* JavaScript (Vanilla)
* LocalStorage (for persistence)

---

## 📱 How It Works

1. User logs water intake
2. Progress updates visually
3. Data stored locally
4. Daily reset ensures fresh tracking
5. Streak increases when goal is met
6. Achievements unlock over time
